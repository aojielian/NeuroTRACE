# Processed inputs

The processed BrainSpan reference has 5,000 genes and six standardized stage profiles; only descriptive stage names were changed. See Supplementary Methods for bin boundaries and observed age ranges. Gandal discovery used processed subject-level cortical mean expression (103 subjects, age range 2.0–67.3 years); this package does not redistribute that individual-level expression input or assert a new raw regional reconstruction. Graph edges and native weights are gene-level derived inputs. Null tables contain 6,000 synthetic matched-random replicates, not individual participants. MDD tables contain six aggregate model summaries; external tables contain 36 aggregate model summaries. Gene weights and all saved coefficients, SE, t, P and FDR are unchanged. The only interval update is the MDD Student-t CI endpoints. Final stage identifier mapping is documented in `stage_labels.tsv`.

# RUN_FIRST

This repository contains the final analysis and figure-generation code for the NeuroTRACE manuscript:

**NeuroTRACE links adult cortical disease modules to developmental timing, genetic convergence, and cross-disorder psychiatric axes**

## 1. Repository purpose

This GitHub repository provides the code release. The accompanying processed data/results release is archived on Zenodo:

**https://doi.org/10.5281/zenodo.20159204**

The GitHub repository and Zenodo archive are intended to be used together:

- GitHub: final analysis scripts and figure-generation scripts
- Zenodo: processed outputs, figure source data, supplementary-table source data, and manifests
- Journal submission: final manuscript, main figures, supplementary figures, and supplementary tables

## 2. What to prepare before running

Before running the scripts, prepare either:

1. the processed data/results from the Zenodo archive, or
2. the public raw datasets listed in Supplementary Table S1 and `docs/input_data_manifest_template.tsv`.

Most reviewers or readers should start from the Zenodo processed data release rather than rerunning all raw-data preprocessing steps.

## 3. Recommended run order

The main analysis scripts are organized by analysis step:

1. `analysis/step02_simulation_benchmark/`  
   Simulation benchmark, hard-condition benchmark, component ablation, and dual-head freeze summaries.

2. `analysis/step03_feature_embedding/`  
   BrainSpan developmental embedding, native disease module derivation, gene-symbol harmonization, and module-stage alignment.

3. `analysis/step05_optimal_transport_alignment/`  
   PPR-based graph diffusion, developmental stage affinity, graph-prioritized genes, and transport summaries.

4. `analysis/step06_cross_cohort_validation/`  
   External ASD validation and matched-random specificity.

5. `analysis/step08_algorithm_strengthening/`  
   Expression/variance-matched random analyses, signed/unsigned scoring baselines, cross-disease scoring, and algorithm-strengthening summaries.

6. `analysis/step10_risk_free_ablation/`, `analysis/step10_transport_null/`, `analysis/step10_zhou2022_genesets_fixed/`, `analysis/step10_independent_genetic_risk/`, `analysis/step10_composition_adjustment/`, and `analysis/step10_single_cell_validation/`  
   Risk-prior ablation, developmental transport nulls, genetic enrichment, composition adjustment, and single-nucleus contextualization.

7. `analysis/step11_robustness_sensitivity/`  
   Hyperparameter, perturbation, alternative-weight, BrainSpan-universe, NNLS, and cross-disease robustness analyses.

8. `analysis/step12_revision_strengthening/`  
   Bootstrap stability, degree-matched graph nulls, alignment-weight sensitivity, and gnomAD constraint validation.

## 5. Environment

The original analyses were run on CentOS 7 using R 4.2.2 and Python 3.10 in an HPC environment.

Environment files are provided as:

- `environment.yml`
- `sessionInfo.txt`

Exact package versions may vary slightly by system. Users should adapt file paths and project-root settings as needed.

## 6. HPC and Slurm

Slurm submission scripts are not included. They are cluster-specific and are not required to understand or reproduce the analytical workflow. Scripts can be run directly with an equivalent R/Python environment after paths are adapted.

## 7. Notes

- Large public datasets are not stored in this repository.
- Processed analysis outputs and figure source data are archived on Zenodo.
- Some scripts retain original project-style path assumptions and may require path edits outside the original HPC environment.
- The final figure scripts and processed Zenodo data provide the most direct route for reproducing manuscript figures.
